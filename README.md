# Base de Datos II - Proyectos y Laboratorios Semestrales

Este repositorio contiene los proyectos y laboratorios semestrales de la materia Base de Datos II, impartida en la universidad autonoma de Chile. A continuación se detallan los contenidos y la estructura del repositorio.

## Estructura del Repositorio

El repositorio está organizado de la siguiente manera:

`Laboratorios/`: Contiene los laboratorios realizados durante el semestre, organizados por número de laboratorio.
`Proyectos/`: Contiene los proyectos semestrales, organizados por número de proyecto.

## Contenido de los Laboratorios

Cada laboratorio incluye:

Un archivo README.md que describe el objetivo del laboratorio, los pasos a seguir y los resultados esperados.

Archivos de código necesarios para completar el laboratorio, en cierto caso para tener respaldos físicos de los archivos de código originales antes de ser modificados por las ramas, para evitar la pérdida de información se usará una metodología de .zip para comprimir los archivos de código originales y mantenerlos en el repositorio de modo que no afecten las ramas de desarrollo en el sistema de control de versiones de git cuando sea requerido.

Además, se incluyen archivos de datos de ejemplo y cualquier otro recurso necesario para la realización del laboratorio. Así como recursos de aprendizaje adicionales, como enlaces a documentación, tutoriales y referencias bibliográficas para continuar con el aprendizaje de los temas tratados en los laboratorios y de la asignatura en general.
